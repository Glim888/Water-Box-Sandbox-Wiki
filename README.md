## About

**Water Box** is a physics-based sandbox simulation game developed by **Gaming-Apps.com**. The game allows players to freely experiment with water, liquids, fire, chemicals, destruction, ragdolls, ships, vehicles, and various materials in an interactive physics environment.

Players can build their own creations, sink ships, cause explosions, experiment with different liquids and chemical reactions, create chain reactions, and test how objects behave under different conditions. The game features realistic fluid and temperature simulations, destructible objects, ragdoll physics, numerous tools and weapons, pre-built experiments, and an online workshop for sharing creations.

With its focus on experimentation and player creativity, Water Box gives players the freedom to build, destroy, simulate, and discover unexpected interactions within its sandbox world.

Water Box has a built-in Online Workshop where players can share creations and set prices in Coins.

This wiki uses English in-game names. The game's subtitle, available elements, controls, and purchases can vary by platform and version. See [News](news/README.md) for version-specific changes.
