# Saving and Loading

[Wiki Home](../README.md) · [Elements and Gameplay Systems](../README.md#explore-the-wiki)

Save an individual construction to reuse it, or save an entire simulation to keep a complete experiment.

<img src="../assets/guides/save.png" alt="The in-game Save icon" width="64">

*Save locally before publishing a creation or replacing the current scene.*

## Object or Simulation?

| Type | Use it for | Loading behavior |
| --- | --- | --- |
| Object | A boat, vehicle, machine, or self-contained assembly | Places the saved construction into a sandbox. |
| Simulation | Terrain, liquids, several objects, or a complete experiment | Opens the saved scene. |

## Save an Object

1. Pause and select the complete construction, including the parts needed by its joints and machinery.
2. Use the selection's **Save** action.
3. Enter a recognizable name and confirm. Reusing a name can show an overwrite confirmation.
4. Find the result under **My Created Objects**.
5. Place a saved copy in a test scene and check that its connections and moving parts still work.

The game can prevent saving selections containing locked elements. Read the displayed requirement before trying again.

## Save a Simulation

Use **Save/Load Simulations** to save a complete scene. This is the useful choice for experiments that depend on the arrangement of terrain, liquids, and multiple constructions.

Save your current work before opening another simulation. Load the saved scene again to compare changes from the same starting point. Keep [Liquid Settings](../systems/liquid-physics.md#liquid-settings) consistent during comparisons.

## Local Saves and Shared Creations

Saving locally does not publish anything. To share a tested save, use **Submit to Workshop** as described in [Online Workshop](online-workshop.md#publish-a-creation).

Downloaded content appears under **My Downloaded Creations**. An Object can be placed in a scene; a Simulation opens its own scene. Access to the elements it contains can still be required.

Local saves can be lost when the app or its data is removed. Keep this in mind before reinstalling.
