# Powers

[Wiki Home](../README.md) · [All Element Categories](../README.md#explore-the-wiki)

Powers act directly on the sandbox instead of remaining as physical objects. Standard Powers manipulate elements and the environment, while Liquid Powers draw liquid materials directly into the scene.

## Standard Powers

| Icon | Element | Description |
| :---: | --- | --- |
| <img src="../assets/elements/powers/gpower_eraser.png" alt="" width="48" height="72"> | <a id="eraser"></a> **Eraser** | Deletes elements and liquids from the sandbox. |
| <img src="../assets/elements/powers/gpower_heat.png" alt="" width="48" height="72"> | <a id="fire"></a> **Fire** | Ignites elements and detonates suitable [explosives](explosives.md). |
| <img src="../assets/elements/powers/gpower_cool.png" alt="" width="48" height="72"> | <a id="freeze"></a> **Freeze** | Cools an area, extinguishes fire, turns lava into stone, and can harm [ragdolls](ragdolls-body-parts-and-chemicals.md). |
| <img src="../assets/elements/powers/gpower_explode.png" alt="" width="48" height="72"> | <a id="explosion"></a> **Explosion** | Creates an explosion at the selected position. |
| <img src="../assets/elements/powers/gpower_pull.png" alt="" width="48" height="72"> | <a id="attract"></a> **Attract** | Pulls nearby elements toward the selected position. |
| <img src="../assets/elements/powers/gpower_circle.png" alt="" width="48" height="72"> | <a id="finger-circle"></a> **Finger (Circle)** | Interacts physically with elements using a circular contact area. |
| <img src="../assets/elements/powers/gpower_rect.png" alt="" width="48" height="72"> | <a id="finger-rectangle"></a> **Finger (Rectangle)** | Interacts physically with elements using a rectangular contact area. |
| <img src="../assets/elements/powers/gpower_rect2.png" alt="" width="48" height="72"> | <a id="finger-rectangle-2"></a> **Finger (Rectangle 2)** | Provides a second rectangular shape for physically moving elements. |
| <img src="../assets/elements/powers/gpower_colorbrush.png" alt="" width="48" height="72"> | <a id="liquid-painter"></a> **Liquid Painter** | Changes the color of liquid particles touched by the brush. |
| <img src="../assets/elements/powers/gpower_gravity.png" alt="" width="48" height="72"> | <a id="change-gravity"></a> **Change Gravity** | Changes the sandbox's gravity to the direction of the swipe. |
| <img src="../assets/elements/powers/gpower_tsunami.png" alt="" width="48" height="72"> | <a id="tsunami"></a> **Tsunami** | Generates a large wave across the sandbox. |
| <img src="../assets/elements/powers/gpower_rain.png" alt="" width="48" height="72"> | <a id="rain"></a> **Rain** | Creates falling water over an area. |
| <img src="../assets/elements/powers/gpower_wind.png" alt="" width="48" height="72"> | <a id="wind"></a> **Wind** | Applies directional wind force to the sandbox. |

| :---: | --- | --- |
| <img src="../assets/elements/powers/gpower_liquid_geo_water.png" alt="" width="48" height="72"> | <a id="water"></a> **Water** | Draws cold water that interacts with fire, lava, and [ragdolls](ragdolls-body-parts-and-chemicals.md) and can evaporate. |

| <img src="../assets/elements/powers/gpower_liquid_geo_lava.png" alt="" width="48" height="72"> | <a id="lava"></a> **Lava** | Draws hot lava that can ignite elements and become stone when cooled. |
| <img src="../assets/elements/powers/gpower_liquid_geo_elastic_lava.png" alt="" width="48" height="72"> | <a id="elastic-lava"></a> **Elastic Lava** | Draws connected lava particles that form hot, jelly-like shapes. |
| <img src="../assets/elements/powers/gpower_liquid_geo_paint.png" alt="" width="48" height="72"> | <a id="colored-liquid"></a> **Colored Liquid** | Draws liquid in a selected color that can mix with other colors. |

## Tips

- Pause the simulation when precise placement is important.
- Use smaller brush sizes for controlled liquid experiments.
- Combine Change Gravity, Wind, Rain, and Tsunami to create environmental scenarios.
