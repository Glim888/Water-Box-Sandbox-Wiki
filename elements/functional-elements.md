# Functional Elements

[Wiki Home](../README.md) · [All Element Categories](../README.md#explore-the-wiki)

Functional Elements apply forces, move materials, control temperature, measure movement, or automate a construction. Many of them have additional settings for strength, range, direction, timing, or selected material.

## Force and Movement

| Icon | Element | Description |
| :---: | --- | --- |
| <img src="../assets/elements/functional-elements/aobjects_thruster.png" alt="" width="48" height="72"> | <a id="thruster"></a> **Thruster** | Applies a strong forward force for rockets, boats, and other vehicles. |
| <img src="../assets/elements/functional-elements/aobjects_forcebox.png" alt="" width="48" height="72"> | <a id="booster"></a> **Booster** | Pushes elements forward when they enter its active area. |
| <img src="../assets/elements/functional-elements/aobjects_fan.png" alt="" width="48" height="72"> | <a id="fan"></a> **Fan** | Blows nearby elements and liquids away in one direction. |
| <img src="../assets/elements/functional-elements/aobjects_pull.png" alt="" width="48" height="72"> | <a id="attractor"></a> **Attractor** | Pulls nearby elements and liquids toward itself. |
| <img src="../assets/elements/functional-elements/aobjects_push.png" alt="" width="48" height="72"> | <a id="pusher"></a> **Pusher** | Pushes nearby elements and liquids away from itself. |
| <img src="../assets/elements/functional-elements/aobjects_expander.png" alt="" width="48" height="72"> | <a id="expander"></a> **Expander** | Alternates between expanding and shrinking; useful for wave generators and moving mechanisms. |
| <img src="../assets/elements/functional-elements/aobjects_balloon.png" alt="" width="48" height="72"> | <a id="balloon"></a> **Balloon** | Generates upward movement and can lift attached elements. |
| <img src="../assets/elements/functional-elements/aobjects_stabilisator.png" alt="" width="48" height="72"> | <a id="stabilizer"></a> **Stabilizer** | Keeps a construction horizontal and helps prevent it from flipping over. |
| <img src="../assets/elements/functional-elements/aobjects_moving_wall_1.png" alt="" width="48" height="72"> | <a id="moving-wall-1"></a> **Moving Wall 1** | Moves from its start point to an end point, jumps back, and repeats. |
| <img src="../assets/elements/functional-elements/aobjects_moving_wall_2.png" alt="" width="48" height="72"> | <a id="moving-wall-2"></a> **Moving Wall 2** | Continuously moves back and forth between two points. |

| Icon | Element | Description |
| :---: | --- | --- |
| <img src="../assets/elements/functional-elements/aobjects_remover.png" alt="" width="48" height="72"> | <a id="destroyer"></a> **Destroyer** | Removes every element that touches it. |
| <img src="../assets/elements/functional-elements/aobjects_blackhole.png" alt="" width="48" height="72"> | <a id="black-hole"></a> **Black Hole** | Pulls nearby elements inward and destroys them. |
| <img src="../assets/elements/functional-elements/aobjects_teleporter.png" alt="" width="48" height="72"> | <a id="liquid-teleporter"></a> **Liquid Teleporter** | Moves liquids from an input point to an output point. |
| <img src="../assets/elements/functional-elements/aobjects_se_spawner.png" alt="" width="48" height="72"> | <a id="element-spawner"></a> **Element Spawner** | Periodically creates the element selected in its settings. |
| <img src="../assets/elements/functional-elements/aobjects_glue.png" alt="" width="48" height="72"> | <a id="glue"></a> **Glue** | Causes elements that touch it to stick. |
| <img src="../assets/elements/functional-elements/aobjects_filter_liquidcolor.png" alt="" width="48" height="72"> | <a id="liquid-color-filter"></a> **Liquid Color Filter** | Allows only liquid particles matching a selected color to pass. |
| <img src="../assets/elements/functional-elements/aobjects_converter_liquidcolor.png" alt="" width="48" height="72"> | <a id="liquid-color-changer"></a> **Liquid Color Changer** | Changes touching liquids to the selected color. |
| <img src="../assets/elements/functional-elements/aobjects_effervescent_tablet.png" alt="" width="48" height="72"> | <a id="water-magic-tablet"></a> **Water Magic Tablet** | Changes the color of [water](powers.md#water) after it is placed in the liquid. |

## Temperature and Measurement

| Icon | Element | Description |
| :---: | --- | --- |
| <img src="../assets/elements/functional-elements/aobjects_heater.png" alt="" width="48" height="72"> | <a id="heater"></a> **Heater** | Raises the temperature of nearby elements. |
| <img src="../assets/elements/functional-elements/aobjects_cooler.png" alt="" width="48" height="72"> | <a id="cooler"></a> **Cooler** | Lowers the temperature of nearby elements. |
| <img src="../assets/elements/functional-elements/aobjects_tacho.png" alt="" width="48" height="72"> | <a id="speedometer"></a> **Speedometer** | Displays the speed of an attached element or vehicle. |

## Tips

- Open an element's settings to adjust its range, power, direction, or interval.
- Combine an Element Spawner with a Destroyer to build repeatable test systems.
- Use a Stabilizer and Speedometer when testing vehicles.
